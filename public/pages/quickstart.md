## Setup Flow

```
/start     → Initialize the bot, see your tier
/tutorial  → Interactive walkthrough (strongly recommended)
/settings  → Set min odds, min value %, min avg minutes, timezone
/markets   → Toggle on only the markets you actually bet
/toggle    → Enable live push alerts
```

## Reading an Alert

```
⚡️ PLAYER PROP VALUE ALERT ⚡️
🏟 Milan vs Monza | Serie A
👤 Samuele Birindelli (Monza) | RM
⚽️ To score anytime
📚 Bookmaker Odds: 8.5
🖥 Model Odds: 2.86
📈 Value: 197.2%
💰 Stake: 0.5u
```

**Value %** = ((Bookmaker ÷ Model) − 1) × 100. Positive = mathematical edge.

**📉 indicator** = odds have shortened since alert. Act fast.

**Per Game** = last 10 results, left = most recent. Asterisk (*) = started.

## Do's and Don'ts

**✅ Do:**
- Complete /tutorial before anything else
- Check multiple bookmakers - Bet365 links are starting points
- Stake consistently: 1u = your average bet, never >2% of bankroll
- Use /fixture for deep pre-match analysis
- Track all bets with /track or a spreadsheet

**❌ Don't:**
- Take every alert - this is a research tool, not a tipster
- Chase losses - the edge is long-term
- Ignore recommended stakes - they factor in probability, not just value
- Forget rotation - check /today before markets open

> "The main thing with the bot is it's NOT a tipster, taking every alert it sends isn't the way to go, but use it as a tool to point you in the right direction you can't go wrong." - Jay (Prof. X), Creator
