# Arb Bot - Personalization

## /settings Menu Options

| Setting | Description |
|---|---|
| 💷 Default Stake | Total amount per arb. Bot splits across both sides. |
| 📊 Min Margin | Minimum profit %. Recommended: 1.5–2.0% |
| 📚 Bookmakers | Enable only books with funded accounts |
| ⚽ Sports Filter | Select sports to receive alerts for |
| 🔄 Bookmaker Clones | Alternatives if primary is restricted (Kambi platform shares) |
| ⏰ Time Filter | 1 hour / 2 hours / 6 hours / 12 hours / 1 day / 3 days / 7 days |
| 🏦 Exchange Commissions | Set %. Default: Betfair 2% |
| 🔄 LAY Arbs | Toggle LAY betting alerts on/off |

## Recommended Bookmaker Setup

**Tier 1 - Essential:** Bet365, Betfair Exchange - highest limits, non-negotiable.

**Tier 2 - Recommended:** Pinnacle, Smarkets - sharp books, rarely restrict winners.

**Tier 3 - Expand:** Ladbrokes, William Hill, Coral - UK high-street books.

## Avoiding Gubbing (Account Restrictions)

- Round stakes to nearest £5/£10 (avoid exact calculator numbers)
- Don't always bet the maximum allowed
- Mix in occasional non-arb bets on accounts you want to keep
- Don't withdraw immediately after every won arb

## Palpable Errors

When a bookmaker accidentally offers clearly wrong odds, they may void bets citing "palpable error." The bot filters out extreme outliers, but always sanity-check arbs above 5% margin.
